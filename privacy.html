Privacy Policy

YT Channel Tools · Effective 2026-11-19

YT Channel Tools ("the tool") is a private set of scripts used by a single operator to manage the operator's own YouTube channels. This policy explains what data the tool accesses through YouTube API Services and how that data is handled.

YouTube API Services

The tool uses YouTube API Services. Users of the tool are bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the tool accesses

  • OAuth tokens for the operator's own Google account and the YouTube channels the operator authorizes.
  • Channel and video data of those channels: channel IDs and titles, video metadata, playlists, captions, comments, and upload status.
  • Analytics of those channels: views, watch time, audience retention and similar aggregate reports from the YouTube Analytics API. These reports are aggregated and do not identify individual viewers.
  • Public data from YouTube: public video and channel statistics (titles, view, like and comment counts) used for topic research.

How the information is used

The data is used only to upload and manage the operator's own videos, to schedule publishing, and to review channel performance and research video topics. It is not used for advertising, profiling, or any purpose unrelated to running these channels.

Storage and security

  • OAuth tokens and client credentials are stored only on the operator's own computer, in a folder outside any code repository, readable only by the operator's user account.
  • Retrieved YouTube data is stored locally on the same computer for research and reporting. It is not uploaded to any other server.
  • Stored YouTube API data is refreshed or deleted in line with the YouTube API Services Developer Policies; data that is no longer needed is deleted.

Sharing

The tool does not sell, rent, or share any data with third parties. No data is disclosed to anyone other than the operator.

Cookies and tracking

The tool has no web interface for end users and does not place cookies or tracking technologies on any device. This website does not use cookies or analytics.

Revoking access

Access granted to the tool can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. After access is revoked, the tool can no longer read or change the channel, and its stored tokens stop working.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

Questions about this policy can be filed as an issue at github.com/CatDidIt-Studio/yt-channel-tools/issues.
