YT Channel Tools

A private tool for managing the operator's own YouTube channels.

YT Channel Tools is a set of command-line scripts that one person uses to run a small number of their own YouTube channels. It is not offered to the public, and no one else signs in to it.

What it does

  • Uploads videos the operator produced to the operator's own channels and schedules their publish time.
  • Updates titles, descriptions, thumbnails, captions and playlists on those channels.
  • Reads the channels' own analytics (views, watch time, retention) to plan future videos.
  • Reads public video statistics through the YouTube Data API to research topics.
